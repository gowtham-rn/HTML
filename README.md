# HTML Practice

## About This Repository
This repository contains my HTML practice files created while learning the fundamentals of HTML. It includes examples of different HTML elements and tags.

## Topics Covered
- Basic HTML document structure
- HTML elements and tags
- Headings and paragraphs
- Links and images
- Lists and tables
- Forms and input elements
- Other HTML elements and attributes

## Project Structure
- `index.html` – HTML practice examples
- `index2.html` – Additional HTML practice
- `images/` – Images and other visual assets used in the pages

## Technologies Used
- HTML5
- Visual Studio Code

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser to view the page.
